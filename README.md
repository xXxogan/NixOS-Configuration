# NixOS Configuration

Личная конфигурация NixOS (flake + home-manager) для виртуальной машины VMware (aarch64).

## Состав репозитория

- `flake.nix` — точка входа, описывает систему `nixos`
- `configuration.nix` — системная конфигурация (GNOME, автологин, сеть, локаль)
- `home.nix` — пользовательская конфигурация (home-manager)
- `hardware-configuration.nix` — конфигурация железа (для конкретной VM)
- `disko.nix` — декларативная разметка диска

## Установка на новую VM (с нуля, одной командой)

Это самый быстрый способ: разметка диска, установка и настройка системы происходят автоматически через [`nixos-anywhere`](https://github.com/nix-community/nixos-anywhere) и [`disko`](https://github.com/nix-community/disko).

### Требования

- **Целевая машина**: новая VM в VMware Fusion/Workstation (aarch64), с смонтированным NixOS installer ISO
- **Хост-машина** (ваш ноутбук/компьютер): установлен [Nix](https://nixos.org/download) с включёнными flakes

### Шаг 1. Создайте VM и загрузитесь с NixOS ISO

1. Скачайте [минимальный NixOS ISO для aarch64](https://nixos.org/download#nixos-iso) (Minimal installer).
2. В VMware Fusion/Workstation создайте новую VM, подключите ISO как загрузочный диск.
3. Запустите VM — она загрузится в live-окружение NixOS installer.

### Шаг 2. Узнайте IP-адрес VM

После загрузки live-системы в терминале VM выполните:

```bash
ip a
```

Найдите строку с сетевым интерфейсом (обычно `enp0s...` или `ens...`), в ней будет что-то вроде:

```
inet 192.168.1.123/24 ...
```

Это и есть IP-адрес VM — `192.168.1.123` в данном примере. Запомните его.

> Если IP не появился — проверьте, что сетевой адаптер VM в настройках VMware работает в режиме **NAT** или **Bridged**, и подождите несколько секунд после загрузки.

### Шаг 3. Установите пароль root и включите SSH в live-системе

В NixOS installer SSH обычно уже запущен, но пароль root не установлен. Задайте временный пароль:

```bash
sudo passwd root
```

Введите любой временный пароль дважды — он понадобится только для первого подключения.

### Шаг 4. Проверьте SSH-доступ с хост-машины

С вашего ноутбука/компьютера (там, где склонирован этот репозиторий):

```bash
ssh root@192.168.1.123
```

Введите пароль, который задали на шаге 3. Если подключение прошло успешно — выходите обратно (`exit`), всё готово к установке.

> Если ssh ругается на `Host key verification failed` при повторных установках на тот же IP — удалите старую запись:
> ```bash
> ssh-keygen -R 192.168.1.123
> ```

### Шаг 5. Клонируйте репозиторий (если ещё не сделали)

```bash
git clone https://github.com/xXxogan/NixOS-Configuration.git
cd NixOS-Configuration
```

### Шаг 6. Запустите установку одной командой

```bash
nix run github:nix-community/nixos-anywhere -- \
  --flake .#nixos \
  --build-on-remote \
  root@192.168.14.138
```

Замените `192.168.1.123` на реальный IP из шага 2.

Что произойдёт автоматически:
1. `nixos-anywhere` подключится по SSH к VM.
2. Разметит диск согласно `disko.nix` (полностью удалит текущее содержимое диска).
3. Установит систему согласно `flake.nix` + `configuration.nix` + `home.nix`.
4. Перезагрузит VM — она загрузится уже в готовую, полностью настроенную систему с GNOME и автологином.

### Шаг 7. Проверка

После перезагрузки VM должна автоматически войти в GNOME под пользователем `xogan`. Пароль пользователя нужно будет задать отдельно при первом входе (или заранее прописать через `users.users.<name>.hashedPasswordFile` в `configuration.nix`).

## Применение изменений на уже установленной системе

Если система уже установлена и вы просто хотите обновить конфигурацию:

```bash
cd NixOS-Configuration
git pull
sudo nixos-rebuild switch --flake .#nixos
```

## Возможные проблемы

| Проблема | Решение |
|---|---|
| `disko.nix` ссылается на несуществующий `/dev/sda` | Проверьте имя диска в live-системе командой `lsblk`, поправьте `device` в `disko.nix` |
| Нет доступа по SSH | Убедитесь, что сетевой адаптер VM в режиме NAT/Bridged и что вы в одной сети с хостом |
| `Host key verification failed` | Выполните `ssh-keygen -R <ip>` и повторите попытку |
| Экспериментальные функции Nix отключены на хост-машине | Добавьте флаг `--experimental-features "nix-command flakes"` к команде `nix run` |
